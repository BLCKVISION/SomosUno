# Proyecto: SomosUno

## Propósito y Contexto
SomosUno es una plataforma de respuesta y coordinación de crisis, actualmente enfocada en la asistencia durante desastres naturales (como sismos o terremotos) en Venezuela. Su objetivo principal es centralizar la información vital en tiempo real para ayudar a ciudadanos y autoridades a tomar mejores decisiones.

## Funcionalidades Core
1. **Mapa de Crisis en Tiempo Real:** Visualización geolocalizada de la situación a nivel macro y micro.
2. **Gestión de Personas:** Registro y búsqueda de personas "A Salvo" y "Desaparecidas".
3. **Centros de Ayuda:** Ubicación de hospitales, refugios y centros de acopio con actualización de estado e inventario.
4. **Evaluación de Daños (Edificios):** Módulo para reportar daños estructurales usando Inteligencia Artificial (OCR) para leer planillas o reportes rápidamente.
5. **Monitoreo Sísmico:** Sincronización en vivo con la API internacional de la USGS (United States Geological Survey) para reportar sismos cercanos.
6. **Presencia:** Contador en vivo de usuarios activos colaborando en la plataforma.

## Stack Tecnológico Actual
- **Frontend:** Angular 18 (TypeScript).
- **Backend:** NestJS (Node.js/TypeScript) configurado como API REST.
- **Base de Datos:** Supabase (PostgreSQL) manejando también autenticación.
- **Mapas:** Leaflet con mapas de alto rendimiento (CartoDB).
